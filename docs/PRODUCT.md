## Archive

The Archive contains existing photographic work.

Users can:

- Browse categories.
- Open individual photographs.
- View photograph details.
- Search by Photo ID.
- Purchase available photographs.
- Request prints.
- Request licensing when applicable.

### Example

`Nº 212`

A Photo ID is both a technical identifier and a simple way for someone to request a specific photograph.

## Studio

The Studio is for commissioned photography.

Users can:

1. Select a service.
2. Provide project information.
3. See an estimated price/range when possible.
4. Submit a request.
5. Receive a final quote.
6. Confirm/book the project.

Avoid presenting estimates as guaranteed prices unless the pricing model supports it.

## Individual photo page

A photo page should focus on the image first.

Possible information:

- Photo ID
- Category
- Photographer
- Date
- Location
- Tags
- Availability
- Purchase options
- Licensing options

## Homepage

The homepage should behave more like an editorial entry point than a conventional photographer portfolio.

Suggested structure:

- Nostos introduction
- Featured photograph/work
- Recent archive
- Short Studio introduction
- Link to explore the Archive
- Link to work with Nostos
