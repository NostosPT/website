# Nostos — Documentation

Nostos is a photography archive and visual studio.

The platform has two core sides:

- **Archive** — discover, view, purchase and license photographs already created.
- **Studio** — request professional photography services and receive an estimate/quote.

The website is the primary platform. Social media is optional and should act as a secondary discovery channel, not as the core product.
