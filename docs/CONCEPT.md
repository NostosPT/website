# Nostos — Core Concept

## Positioning

**Nostos is a photographic archive and visual studio.**

It combines:

1. A curated archive of photographs.
2. A marketplace for selected photographs.
3. A photography studio for commissioned work.

## Core idea

**Archive what has been photographed. Create what has not.**

- **Archive:** existing work.
- **Studio:** commissioned work.

## Brand direction

Nostos should feel editorial, intentional and photographic — not like a generic photographer portfolio or stock-photo marketplace.

The name can subtly connect to ideas of **place, memory, return and moments**, without relying heavily on Greek mythology.

## Platform rule

The website should be the source of truth.

Social media can be used for discovery, but important actions should lead back to Nostos.
