# Nostos — Content Model

## Categories

Initial categories can include:

- Street
- Urban
- Automotive
- Portrait
- Landscape
- Events

Categories should remain flexible and should not be hardcoded into the product architecture.

## Photograph

Conceptually, a photograph contains:

- Photo ID
- Photographer
- Original file
- Display image
- Thumbnail
- Category
- Collection
- Date
- Location
- Tags
- Description
- Visibility
- Availability
- Pricing
- Licensing options
- Watermark status

## Watermark

Watermarks should be subtle and consistent.

Example:

`NOSTOS`
`Nº 482`

The watermark protects previews without destroying the photograph visually.

## Street Photography

Street photography requires additional consideration because photographs may contain identifiable people.

Before commercialising this area, define the legal/privacy workflow for Portugal and the EU, including when consent, notices, licensing or other safeguards may be required.
