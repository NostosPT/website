# Nostos — Admin

The admin area manages the platform internally.

## Main areas

- Dashboard
- Photos
- Collections
- Photographers
- Orders
- Service Requests
- Customers
- Settings

## Photographer

A photographer is an owner/contributor associated with photographs.

Possible data:

- Name
- Profile
- Bio
- Social links
- Published photographs
- Role/permissions

## Photograph management

Admins should be able to:

- Upload photographs.
- Edit metadata.
- Assign categories/collections.
- Assign photographers.
- Generate/manage Photo IDs.
- Configure pricing.
- Configure availability.
- Publish/unpublish work.

## Orders

Track:

- Customer
- Photograph
- Product/license
- Amount
- Status
- Payment status
- Delivery/download status

## Service requests

Track:

- Customer
- Requested service
- Project details
- Estimate
- Quote
- Status
- Internal notes

"BRANDING.md": """# Nostos — Brand Direction

## Character

Nostos should feel:

- Editorial
- Minimal
- Photographic
- Quiet
- Intentional
- Premium
- Human

Avoid:

- Generic photographer clichés.
- Excessive animations.
- Stock-photo aesthetics.
- Overloaded dashboards on the public site.
- Generic SaaS language.
- Heavy branding inside photographs.

## Language

Keep public copy concise.

Avoid phrases such as:

> Capturing your special moments.

Prefer language that describes the archive, visual work and studio directly.

## Core vocabulary

- Archive
- Studio
- Collection
- Photograph
- Photographer
- Project
- Request
- License
- Print

## Possible positioning line

> A photographic archive and visual studio.

This is a starting point, not necessarily the final tagline.
