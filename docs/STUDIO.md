# Nostos — Studio

## Purpose

Studio handles commissioned photography.

## Initial services

- Automotive
- Portrait
- Event Coverage
- Weddings
- Commercial
- Other / Custom

## Request flow

### 01 — Service

What do you need?

### 02 — Project

Collect only information needed to understand the project:

- Date
- Location
- Duration
- Number of people/vehicles
- Intended use
- Additional information

### 03 — Estimate

Show an estimate only when enough information exists.

Prefer:

- `From €120`
- `Typical projects: €120–€300`

over pretending the estimate is a final quote.

### 04 — Request

The user submits the project.

The team reviews it and provides the final quote.

## Future
